# Árkád Hajsza

Böngészős játék: Krisztina kergeti Szabit a győri Árkádban, mert ruhákat akar venni – de a pénztárca Szabinál van.
A kis Zalán játékokat dob anya útjába, hogy apa meglógjon.

## Indítás

Nyisd meg az `index.html`-t egy böngészőben (nincs szükség telepítésre vagy szerverre).

## Irányítás

| Billentyű | Mit csinál |
|---|---|
| ▲ / ▼ vagy W / S | Szabi sávot vált |
| SPACE | Zalán eldob egy játékot Krisztina elé |
| P / Esc | Szünet |

Mobilon a képernyőn lévő gombokkal vagy fel/le húzással lehet játszani.

Szedd fel a kávét (gyorsulás), a játékokat (Zalán lőszere) és a bankjegyeket. Az akciós boltok néha elterelik Krisztina figyelmét.
